# 拼谷工作台

给分装拼团用的独立工作台。支持导入拼谷助手排表、肾表及 JPG 导出、归仓、转单和排发管理。

## 本机启动

1. 安装 Python 3。在 Mac 上解压后双击「启动工作台.command」，或在终端进入项目目录执行 `python3 启动.py --open`。
2. 首次启动时，在终端分别设置管理员密码和群访问码。管理员密码至少 12 个字符，群访问码至少 8 个字符，两者须不同。
3. 打开 http://127.0.0.1:8765/ ，选择「群主 / 管理员」，登录后点「团设置」。填写团名，可上传 280 KB 以内的 PNG 或 JPG 头像。
4. 导入自己的排表。团员使用排表中的完整昵称和群访问码登录。共用访问码持有人可用任何已登记的昵称登录。

## 使用说明

### 团主 / 管理员

1. **导入排表**：进入「导入排表」，上传拼谷助手导出的 Excel，或把完整排表粘贴到「排表内容」。点「校验排表」，核对新增明细、毫升数、应收和要瓶标签，再确认导入。
2. **核对肾表**：在「拼谷总览」点「查看明细」，可修改毫升数、容器用量和手动应收金额。整款墨水改价用「整瓶改价」，先预览再确认。点「导出肾表 JPG」可预览并保存图片，方便发到群里。
3. **收款和归仓**：核对到账后，在明细中标记已交肾，也可按团员或墨水批量确认。整款墨水到齐时点「一键归仓」，分批到货时勾选对应明细再登记。
4. **排发和寄出**：在「审核申请」处理团员的发货申请。在「排发管理」按收件团员展开明细，核对邮费后标记已付。同一包裹的明细可一起勾选，点「登记同包裹寄出」并填写单号。
5. **维护团务**：在「时间线 / 备注」修改成团、交肾截止及可排发时间。新导入的墨水默认以导入时间为成团时间，交肾截止为三天后。散团时在该款墨水明细页点「标记散团」，需要恢复时点「恢复墨水」。

### 团员

1. **查认领**：从「团员查询」输入排表里的完整昵称和群访问码。首页显示认领明细、已付金额、未交肾总额和当前认领量，时间线在页面底部。
2. **交肾**：按各团群公告付款并填写备注。管理员核款后会更新工作台上的状态。
3. **申请发货**：在「办理事项」选择「申请分装发货」，勾选已交肾且已归仓的明细并提交。审批进度和快递单号可在工作台查看。
4. **转单**：选择「发起转单」，填写接单人的完整昵称。若只转出部分墨水，只勾选一条明细并填写毫升数。接单人到「转单记录」确认。原认领人仍按原肾表交肾，转单款由双方自行结算。

## 部署与数据

默认只监听本机。部署时可用 `MOSHUI_HOST`、`MOSHUI_PORT` 设置监听地址与端口。后台首次启动时，请通过部署平台的私密环境变量设置 `WORKBENCH_ADMIN_PASSWORD` 和 `WORKBENCH_GROUP_CODE`。初始化后这两项从数据库读取。

每个团运行独立实例，使用不同的数据目录（`WORKBENCH_DATA_DIR`）和端口。订单、团设置、转单和排发记录存于数据目录的 `workbench.sqlite3`。备份完整实例时，先停止服务再复制数据库。正式对外访问时，建议在 HTTPS 反向代理后运行程序。

仓库只需包含程序文件。排表、数据库和部署凭据应存放在实例或本机。
